Static Site Generators

Self-hosted alternatives to Squarespace, Wix and GitHub Pages.

What people say

  • a simple website with no logins
  • a documentation site
  • a portfolio

Why people self-host it

People leave Squarespace, Wix, GitHub Pages for it. Why, strongest first: cost, control.

Does it suit a machine of your own?

Usually better elsewhere a static site is usually best on free static hosting (Cloudflare Pages, Netlify, GitHub Pages), with no machine to keep up; self-host it only if the person wants it on their own machine

Questions that decide it

  • does anything need a login or an editor?
